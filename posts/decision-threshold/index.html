A Steerable Decision Threshold in a Planning Agent

2026-08-28

Summary

We trained a DRC agent, a Resnet CNN and a Vision Transformer using reinforcement learning and a prefix transformer using imitation learning in a maze environment designed to require a utility calculation to determine which objective should be prioritised.

Across every training run that converged we found a subset of weights that linearly encoded the decision threshold. We were able to write to this with the same accuracy as finetuning our agent to that new objective.
